# Starship Debug

## Description

**Starship Debug** is an educational game designed to teach newcomers to computer science fundamental CS concepts in a fun and interactive way. The game includes puzzles on topics such as pathfinding algorithms, sorting algorithms, time complexity, and flow control.

## How to Play
Open the built executable file and click **Play** on the main menu. Roam around the ship and complete puzzles to check off tasks from your list and finish the game.

## Deployment

### Prerequisites
To build the executable, ensure you have:
- Unity Hub and Unity Editor installed (specific version: **2022.3.0f1** or compatible).
- Windows, macOS, or Linux OS.
- .NET SDK installed for C# development.
- Required Unity build support modules for your target platform.

### Building the Game for PC
To build the game for Windows, macOS, or Linux:
1. Open the project in Unity.
2. Go to **File > Build Settings**.
3. Select your target platform (Windows, macOS, or Linux).
4. Click **Switch Platform** if necessary.
5. Ensure all relevant scenes are added to **Scenes In Build**.
6. (Optional) Configure additional settings under **Player Settings**.
7. Click **Build**, then choose an output folder (e.g., `Build/Windows/`).
8. Once the build is complete, an executable will be created (`.exe` for Windows, `.app` for macOS, or equivalent for Linux).
